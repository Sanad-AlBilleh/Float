# Float

Float is a planned student allowance tracker focused on one question: **what can I spend today while keeping money for bills and savings until my next allowance?**

## Project status

Requirements and design only. No application has been implemented, no tests have been run, and professor approval has not yet been recorded. Obtain approval before writing application code, as required by Assignment 1.

The proposed stack is Python/FastAPI with SQLite and a simple interface served by the same process. The product starts from a €750 monthly allowance, with manual transaction entry and EUR as its sole currency.
